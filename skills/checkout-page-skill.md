# Checkout Page Skill

The Checkout Page Skill helps an AI agent design, write, audit, build, and validate conversion-focused checkout experiences without breaking the registration or payment system behind them.

## The core distinction

- **Checkout page:** the complete landing page and URL, including the offer, proof, FAQs, guarantee, header, footer, and the place where checkout is rendered.
- **Checkout widget:** the contact, consent, order-summary, payment, validation, and confirmation interface embedded inside that page.

The skill can improve the page while preserving the widget's DOM, props, pricing, registration handlers, analytics, consent, payment processing, and success behavior.

## What it covers

- Direct-response checkout structure and Caveman Copy.
- Dynamic offer, event, pricing, savings, and availability validation.
- Checkout widget and payment-plumbing protection.
- Widget-first mobile ordering, anchors, sticky behavior, and accessibility.
- Honest optional consent and conditional SMS disclosure.
- Safe query-gated theme experiments and reversible live replacements.
- Checkout success states, post-purchase thank-you pages, and complete QA.
